Oppvera Watch is meant for **marketing and GEO learners**, not just developers. If you have never installed Node, Docker, or a command-line tool before, that is normal—follow [Local Setup](/local-setup) step by step.

Install steps in this repo are still being simplified. Expect some manual setup for now.

## Recommended path for learners

**Start with [Local Setup](/local-setup).** It runs on your Mac or Windows laptop, uses your normal browser login for ChatGPT and other tools, and is the easiest way to explore GEO scores hands-on.

Self-hosted VPS setup is for always-on tracking and recurring schedules. **Most learners should skip it.** It requires a VPS, a residential proxy subscription, and careful review of AI provider terms—not just running MIT-licensed code on a laptop.

## What you need before opening the app

Every local setup needs these installed and running:

1. **Node.js 20+** — runs the Oppvera Watch app on your machine
2. **pnpm 10+** — installs the project (a package manager; see the local guide)
3. **Docker Desktop** — runs the background databases the app needs
4. **Git** — downloads the project from GitHub
5. **An OpenAI or Anthropic API key** — scores captured AI answers (you add this to a config file)

Full install steps for each item are in [Local Setup](/local-setup):

- [Install Node.js](/local-setup#install-nodejs)
- [Install pnpm](/local-setup#install-pnpm)
- [Install Docker Desktop](/local-setup#install-docker-desktop)
- [Install Git](/local-setup#install-git)

You also need accounts for the AI tools you want to measure (ChatGPT, Gemini, etc.) so you can sign in during setup.

## Choose your setup

- [Local Setup](/local-setup)
  Run Oppvera Watch on your Mac or Windows machine. Best for learning, demos, and experiments.

- [Self-Hosted Setup](/self-hosted-setup)
  Advanced VPS deployment for always-on tracking. Not recommended for courses—requires proxy services and separate compliance review.

## Which path should you pick?

- **Marketing / GEO learning:** choose **Local**. Work through [Local Setup](/local-setup) in order.
- **Advanced self-hosting experiments:** choose **Self-Hosted** only after you understand VPS, proxy, and provider-term requirements.

For environment variable details, see [Environment Variables](/environment-variables). For command reference, see [Reference](/api-reference).
